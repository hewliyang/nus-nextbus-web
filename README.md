A minimal **PWA** for fetching and displaying NUS Internal Shuttle Bus routes & arrival timings because... too many NUS apps.

## Features
- Geolocation 📍
- Reactive Search 📑
- Bookmarking 📒
- Dark Mode 🌑
- Add to home screen 📱

## Developing

Install dependencies

```bash
pnpm install

cp .env.example .env # setup ur config here
```

Run the dev server

```bash
pnpm run dev
```
